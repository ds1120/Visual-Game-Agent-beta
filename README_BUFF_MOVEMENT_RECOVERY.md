# 버프 재사용과 이동 복구

MD 문서는 실행 설정으로 자동 로드되지 않습니다. 실제 설정은 `app/profiles/<게임>/hud.json`, `input.json`, `navigation.json`과 Python의 Qwen 프롬프트에서 읽습니다.

## 버프

등록 아이콘은 `assets/buffs/*.png`, 버프창 영역은 `hud.json`의 `regions.buffs`입니다. 현재 디아블로 프로필에는 `buff_001.png`가 있고 `CAST_BUFF` 키는 `4`입니다. 영역은 전체 화면으로 저장되어 있습니다. 정확한 버프창 범위를 사용하면 오탐과 처리 비용을 줄일 수 있습니다.

OpenCV는 최대 초당 2회 버프를 확인합니다. 등록 아이콘이 처음부터 없거나 사라진 상태가 5초 지속되면 `CAST_BUFF` 키를 한 번 누릅니다. 아이콘이 계속 없으면 5초 간격으로 재시도하며, 확인되면 반복 입력을 멈춥니다. HP 확인 실패·중단·게임 창 비활성·오래된 측정에서는 입력하지 않습니다. 버프 키 전송을 버프 활성으로 간주하지 않습니다. 여러 버프별 개별 키 매핑은 현재 지원하지 않으며 모두 등록된 CAST_BUFF 키를 사용합니다. 큰 버프 검색 영역은 축소하여 비교합니다.

## 이동

현재 디아블로 IV 미니맵은 우측 상단(X 82%, Y 4.2%, 너비 16.8%, 높이 19.5%), 플레이어 위치 50%/50%입니다. OpenCV가 밝은 통로와 진한 지형을 구분하고 스크롤을 추적하여 이동 기록을 유지합니다. 코너에서는 클릭 거리를 줄이고, 진전 없는 방향을 잠시 피합니다. 자세한 설정과 한계는 `MINIMAP_MAPPING.md`를 참고하세요. 실제 게임의 UI 배율·화면 비율에 맞는지 실게임 확인이 필요합니다.

미니맵에서 통로를 확인하지 못하면 해당 측정을 유효한 경로로 취급하지 않습니다. GameBot 버전은 이때 Qwen 객체와 OpenCV 추적 결과의 화면 장애물을 검사하면서 설정된 이동거리(step_fraction)를 사용합니다. 미니맵 미확인만으로 30% 설정을 8%로 덮어쓰지 않습니다. Qwen의 이동 지시도 이 경로를 거칩니다. 경로가 2초 이상 차단되어 이동 입력이 성공하지 못하고 신뢰할 수 있는 로컬 지도도 없으면 자동사냥 중 통합 Qwen 장면 재분석을 요청합니다. 분석 요청은 SCENE의 최소 호출 간격을 따릅니다. 입력은 최신 캡처·전경·플레이어 HP·장애물 검증을 통과해야 합니다. HP 미탐색의 가림 확인용 짧은 이동은 별도로 유지됩니다.

이번 변경은 버프 UI나 버프 이미지 API를 복구하지 않습니다. 인식과 자동 키 입력은 Agent 내부에서 수행합니다.

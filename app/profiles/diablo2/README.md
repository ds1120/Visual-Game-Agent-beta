# 디아블로2 개발 시작점

## 구현 위치

- `agent.py`: `Diablo2Agent`. 공통 프로그램 기반인 `app/ai/profile_agent.py`만 상속합니다. 디아블로4 Agent는 상속하거나 import하지 않습니다.
- `runtime.json`: 디아블로2 전용 실행 설정. 현재 HUD 읽기는 꺼져 있습니다.
- 기존 JSON, `GAMEPLAY.md`, 이미지와 기억은 보존했습니다. 기존 기록은 참고 자료이며 동작이 검증된 구현이라는 의미는 아닙니다.

현재는 개발용 기반입니다. 캡처·웹·프로파일 편집·모델 연결·핫키 수신·중단·RELEASE는 공통 기능으로 사용합니다. 게임별 이동·공격·스킬 자동 입력은 구현 대기로 차단합니다.

## 이후 작업

1. 디아블로2 창 제목, 캡처와 HUD를 확인합니다.
2. 게임별 HUD 센서를 `profile.py`에 추가하고 `app/profiles/registry.py`에 등록합니다.
3. 지도와 플레이어 위치, 이동 규칙을 `agent.py`와 `navigation.json`에 구현합니다.
4. 적 판별·공격·스킬 규칙을 독립적으로 구현하고 실제 바인딩을 등록합니다.
5. 입력 검증과 회귀 테스트를 통과한 기능부터 활성화합니다.

디아블로4의 화살표, 빨간 몬스터 HP바, Space 안내, 미니맵 색상·투영, HUD 좌표를 디아블로2 기본값으로 사용하지 않습니다.

## 프로파일 선택

웹 게임 목록에서 디아블로2를 선택한 뒤 프로그램을 재시작합니다. 선택은 `app/profiles/active_game.json`에 저장됩니다. 현재 선택은 디아블로4로 유지했습니다.

# 디아블로 II 레저렉션 준비 프로필 이동·전투

현재는 독립 개발용 기반이다. 아래 규칙과 기존 JSON은 참고 자료이며 자동 이동·전투 구현은 아직 적용되지 않았다. 디아블로4 Agent를 상속하지 않고 이 폴더의 agent.py에서 새로 구현한다. 구현 전 자동 입력은 차단한다.

이 문서는 ii 프로필을 선택할 때 적용합니다. 실제 지도·HUD·적 HP·키의 보정 완료를 의미하지 않습니다. 사용자 중단·입력 검증과 저장한 JSON 설정이 우선합니다.

- 이동은 미니맵만 읽어 로컬 중앙 경로를 따른다. 이동 중 전체 화면 Qwen 재분석은 하지 않는다. 전투 조우 시 기본 화면을 분석하며 HP·적 조우 감지는 OpenCV로 계속 확인한다. 미니맵이 없거나 미보정이면 일반 이동을 중단한다.
- 미니맵의 첫 꺾임까지만 클릭 거리를 투영한다. 192px 지도 1px당 1080p 화면 12px는 초기 추정값이며 게임 확대율에 맞춰 navigation.json의 screen_pixels_per_map_pixel을 보정한다. 확인 경로보다 멀리 클릭하지 않는다.

- 디아블로 II에는 디아블로 IV의 빨간 바=적 규칙을 적용하지 않는다. 확정된 적과 보정된 적 HP 피드백을 사용하고 NPC·아군·중립·모르는 객체는 공격하지 않는다.
- 반투명 지도는 벽 윤곽선 모드를 사용한다. 별도로 보정한 지도 영역·벽 색상·플레이어 위치가 필요하다. 화면 배경이나 지도 밖으로 열린 영역을 통로라고 단정하지 않는다.
- 클릭 이동을 사용하고 회피는 이동 후퇴로 처리한다. 회피 때문에 Space 키를 보내지 않는다. 공격 버튼과 물약·스킬·상호작용 키는 이 프로필의 실제 바인딩을 따른다.
- 원거리/근거리 선택과 사거리는 이 프로필의 input.json을 따른다. 원거리는 거리 확보 후 공격하고, 근거리는 지정 거리까지 접근한다.
- 하단 HUD를 피하고 보정한 플레이어 발 위치에서 통로 중앙을 따라 이동한다. 실제 이동 정체는 중앙 복귀 → 지나온 길 후퇴 → 다른 통로 탐색으로 복구한다.
- 미확인 스킬·버프 키는 차단 설정을 존중한다. 필요한 정보는 사용자에게 질문하며 다른 게임의 기억·색상·키를 가져오지 않는다.

```gameplay-settings
  }

```

## 이동 목표 유지와 입력 해제 (2026-10-08)

보정된 미니맵 매핑과 클릭 이동을 사용할 때, 탐색·사용자 이동은 검증된 목표 지점을 한 번 클릭한 뒤 미니맵의 이동 위치와 남은 통로를 확인합니다. 포인터 이동 또는 이동 명령 실행 중 같은 이동 클릭을 큐에 더 넣지 않습니다. 목표 도착(지도 기준 2px 이내), 새 장애물, 이동 정체, 지도 구간 변경, 미니맵 미확인 또는 진행 없는 시간 제한이 생기면 로컬 경로를 다시 검증합니다. 적 발견 시 전투 정책을 우선하며 물약·회피·근접 접근·원거리 간격 조절은 이 클릭 유지와 별도로 처리합니다. 미니맵은 0.1초 간격으로 갱신합니다. 실제 위치 변화가 1.2초 동안 없으면 즉시 경로를 다시 판단합니다.

STOP은 키·마우스 유지 입력을 해제하며 플레이어 중앙 (0.5, 0.5)을 다시 클릭하지 않습니다. 게임이 이미 받은 지점 이동 자체는 남은 짧은 경로를 완료할 수 있습니다. 캐릭터·HUD 영역 회피와 최종 클릭 검증은 유지하며, 미니맵을 보정하지 않은 다른 게임에는 이 목표 유지 기능을 적용하지 않습니다.


## 포커스 복귀와 빠른 자동사냥 (2026-10-08)

게임 포커스를 잃으면 캡처·OpenCV·새 Qwen 요청·입력을 일시정지하고 이전 실행 상태를 보관합니다. 포커스가 돌아오면 이전 자동사냥/이동 지시를 자동 복원하며 최신 HP와 지도 확인 후 입력을 재개합니다. 사용자가 직접 중단했거나 HP 미탐색으로 처리 중단된 경우에는 자동 복원하지 않습니다. 이미 서버에 전송한 Qwen 응답은 실행 세대 검증으로 폐기합니다.

자동사냥은 로컬 미니맵 경로 확인 → 이동 지점 클릭 → 이동 중 적 확인 → 적이 있으면 전투, 없으면 경로 확인과 이동을 반복합니다. 일반 이동은 추가 Qwen 응답을 기다리지 않습니다. 탐색·사용자 이동의 전송 간격은 최대 120ms이며 포인터가 이동 중이면 중복 클릭을 큐에 넣지 않습니다. 보정된 지도에서 이동 실제 위치 변화가 1.2초 동안 없으면 경로를 다시 판단합니다.

중앙 클릭 거리(%)는 실제 게임 화면의 짧은 변에 대한 거리입니다. 직선 통로에서는 설정 거리를 사용하고, 코너에서는 연결된 안전한 회전 지점까지 줄입니다. 클릭 직전에는 실제 클릭 좌표까지 통로를 다시 검사하며 다른 경로 분석이 갱신한 거리 값 때문에 기존 좌표를 거부하지 않습니다. 캐릭터·HUD를 피하고 이동 중 HP 가림 확인을 위한 별도 캐릭터 주변 클릭을 삽입하지 않습니다.


## 예정 방향·실제 입력·이동거리 구분 (2026-10-08)

미니맵 이동 기록을 세 가지로 나눕니다. 하늘색 화살표는 검증한 예정 진행 방향, 주황색 ×는 실제 전송한 화면 클릭을 지도에 투영한 추정 목표, 분홍색 궤적은 지도 위치 추적으로 관측한 이동입니다. 전송 대기·실패 좌표를 실제 클릭으로 표시하지 않습니다. 클릭 좌표와 클릭 거리는 화면 기준, 이동거리·시작점 대비 변위·남은 거리는 지도 px 기준입니다. 게임 내 미터로 추측하지 않습니다. 지도 연결 실패나 구간 변경 시 서로 다른 위치의 거리를 합산하지 않습니다.

목표까지 남은 거리와 도착·이동 정체 상태를 함께 표시합니다. 이동 진행이 계속 확인되면 기존 2.5초 제한만으로 목표 클릭을 다시 보내지 않습니다. 시간 경과만으로 목표를 바꾸지 않고, 1.2초 동안 실제 위치 변화가 없거나 새 장애물·적이 나타나면 기존 경로 재판단/전투 정책을 따릅니다. 세부 추적에 Qwen 요청을 추가하지 않습니다.


## 클릭 목표 도착 후 다음 경로 (2026-10-08)

- 탐색·사용자 클릭 이동은 현재 전송한 목표에 도착한 뒤에 다음 경로를 계산하고 클릭한다. 기존 목표 유지 검사는 새 경로 계산보다 먼저 수행한다. 전송 대기·포인터 이동 중에도 다른 예정 방향으로 교체하지 않는다.
- 이동 중 미니맵 갱신은 진행 상태와 남은 통로 확인에 사용한다. 하늘색 예정 방향과 표시 경로는 현재 클릭 목표에 고정하고 지도 스크롤에 맞춰 위치만 옮긴다. 목표 도착은 지도 기준 2px 이내다.
- 진행이 계속되는 동안 4초 방향 변경이나 8초 경과만으로 새 목표를 클릭하지 않는다. 적 발견·긴급 물약/회피·버프·수동 중단·포커스 이탈은 기존 우선순위를 따르며, 새 장애물·지도 연결 실패·1.2초 실제 위치 변화 없음은 재검증/복구 사유다.


## 도착 근처의 다음 경로 준비와 목표 유지 보강 (2026-10-08)

- 현재 목표의 남은 거리가 요청 거리의 15% 이하 또는 지도 4px 이하일 때 다음 경로를 준비한다. 이 단계에서는 실제 클릭을 전송하지 않으며 예정 방향은 현재 목표에 고정한다.
- 지도 2px 이내 도착은 서로 다른 지도 갱신에서 최소 0.08초 간격으로 두 번 확인한다. 같은 캡처를 반복 검사한 횟수는 도착 확인으로 세지 않는다. 도착 후 준비한 다음 경로의 실행 세대·지도 구간·갱신 시각·실제 통로를 다시 검사하고 클릭한다. 준비 경로가 오래되거나 막혔으면 새로 계산한다.
- 버프·물약은 현재 이동 목표를 해제하지 않는다. 자동 아이템 수집/상호작용은 목표 도착까지 기다리며 명시적인 사용자 지시는 우선한다. 공격·회피·중단과 HP/포커스 안전 조건은 기존 우선순위다.
- 목표까지의 직선거리만으로 정체를 판정하지 않는다. 옆으로 움직여도 실제 위치 변화가 있으면 진행으로 인정한다. 1.2초 동안 실제 위치 변화가 없을 때 복구한다. 목표가 해제되면 목표 번호·사유·남은 거리를 기록한다.


## 클릭 연결과 순간 지도 오류 처리 (2026-10-08)
보정된 미니맵 매핑을 사용하는 탐색·사용자 클릭 이동은 클릭 전송 이후의 추가 대기 시간과 MOVE 쿨다운을 0으로 적용한다. 클릭 자체의 입력 완료·포커스·최종 좌표 검증은 유지하고, 키보드 이동과 전투 접근의 지속 시간은 바꾸지 않는다. 현재 목표가 실제로 도착 판정되기 전에는 다음 클릭을 보내지 않는다.
미니맵 정렬 실패 한 번으로 구간을 초기화하지 않는다. 마지막 정상 프레임을 유지해 0.6초 동안 재정렬하고, 회복되면 같은 구간과 목표를 이어 사용한다. 지속적인 실패는 새 구간으로 초기화한다. 지도 측정이 잠시 없거나 HUD/경로 대기 STOP이 발생해도 현재 목표와 실제 클릭 기록을 즉시 지우지 않는다. 통로 표시가 달라져도 실제 위치 변화가 이어지면 목표를 유지한다. 실제 위치 변화가 1.2초 이상 없을 때 막힘 복구를 허용한다. 확인된 정체·전투·회피·명시적 중단·지도 구간 변경은 별도로 처리한다. 측정이 유효하지 않은 동안 새로운 이동 클릭을 허용하지 않는다.


## 도착 후 경로 연결 우선 규칙 (2026-10-08)
현재 클릭 목표는 이동 중 고정한다. 도착 전에는 다음 목표 후보를 계산하거나 예약하지 않는다. 실제 미니맵 위치가 목표 2px 이내인 상태를 서로 다른 측정에서 0.08초 이상 간격으로 확인한 뒤, 확인된 도착 위치에서 다음 경로를 계산하고 즉시 클릭한다. 탐색 이동은 방금 이동한 방향을 다음 경로의 우선 방향으로 이어 사용한다. 버프·물약 및 의미 확인 대기는 새 이동 경로 계산이나 목표 초기화를 일으키지 않는다.
게임은 지점 클릭 후 벽을 돌아 이동할 수 있다. 따라서 통로 표시 변화나 오래된 stuck 플래그만으로 이동 중인 목표를 취소하지 않는다. 실제 위치 변화가 계속되면 현재 목표를 유지하며, 1.2초간 위치 변화가 없을 때 막힘 복구를 허용한다. 지도 좌표 연결 실패가 지속되는 경우·실제 전투/회피·명시적 중단은 안전 조건으로 별도 처리한다. 이동 클릭 이후의 추가 대기와 MOVE 쿨다운은 0이다. 이 규칙이 앞선 도착 전 경로 준비·장애물 표시만으로 목표 해제 규칙을 대체한다.


## 예상 최종 목표 고정과 우회 연결 (2026-10-08)
이동 클릭이 전송되면 예상 최종 목표를 고정한다. 실제 정체가 확인되어도 목표를 다른 탐색 지점으로 바꾸지 않고 동일한 목표까지의 경로를 다시 계산한다. 우회에 필요한 중간 클릭 좌표만 달라질 수 있다. 중간 지점 도착은 최종 도착으로 처리하지 않으며, 같은 목표 번호와 누적 이동 기록을 유지한 채 다음 클릭을 연결한다. 최종 목표에 도착을 확인한 뒤 새 탐색 목표를 찾는다.
경로가 없거나 목표가 현재 검증 지도 밖이면 다른 목표를 임의로 선택하지 않고 같은 목표의 경로 확인을 기다린다. 추측한 장애물·HUD·캐릭터 중앙을 강제로 클릭하지 않는다. 실제 전투/회피·포커스 이탈·지도 좌표 연결 실패·명시적 중단은 기존 입력 제어 조건을 따른다. 클릭 후 추가 대기/쿨다운은 0을 유지한다. 웹 하늘색 예상 목표는 최종 목적지이며 실제 클릭 표시는 중간 클릭 좌표일 수 있다.

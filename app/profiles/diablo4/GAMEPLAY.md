# 디아블로 IV 이동·전투 규칙

JSON > 게임 규칙 > 공통 규칙 순으로 적용한다.

- 몸체에 연결된 단일 빨간 적 HP바로 적을 확인한다. 라헤어·아시아라 등 저장한 아군은 공격하지 않는다.
- 이동은 누적 미니맵 경로와 실제 이동량으로 제어한다. 매 클릭에 Qwen을 기다리지 않는다.
- 사냥시작과 제자리사냥은 기본 공격을 우클릭 유지로 실행한다. 별도 단발 공격은 input.json의 basic_attack_mode를 따른다.
- 버프는 assets/buffs의 등록 이미지 중 하나라도 화면 BUFF 영역에 보이면 입력을 멈춘다. 모두 4초 연속 없을 때만 4번 키를 보낸다. 전송 후 다시 4초 확인하며 크기·숫자 변화도 검사한다.

## 현재 실행 기능과 단축키

- Ctrl+1 / 사냥시작: 이동하지 않는다. 몬스터를 타겟팅하지 않고 현재 마우스 위치에서 우클릭을 유지하며 활성 반복스킬을 함께 실행한다.
- Ctrl+2 / 사냥중단: 대기·실행 입력과 Qwen 작업을 중단하고 입력을 해제한다.
- Ctrl+3 / 이동: 공격 없이 화면 화살표·안내선 및 미니맵 통로를 이용해 이동한다.
- Ctrl+4 / 반복스킬: input.json에 enabled=true로 등록한 스킬을 설정 간격으로 반복한다. 이동 또는 제자리사냥과 조합할 수 있다.
- Ctrl+5 / 제자리사냥: 이동 없이 우클릭을 유지한다. 감지한 몬스터 위치로 타겟을 갱신한다.
- Ctrl+6 / 일시중지, Tab, 마우스 휠 버튼: RELEASE 전송과 모든 자동 입력 정지를 토글한다. 다시 누르면 해제한다.
- Ctrl+7 / 예정 진행 방향 변경: 현재 경로를 재탐색한다.

Ctrl을 유지한 상태에서 다른 번호를 눌러 기능을 조합할 수 있다. 사용자가 마우스 왼버튼을 누르는 동안 이동·공격·스킬을 일시 정지한다.
이전의 이동 중 몬스터 조우 → 전투 → 이동 복귀 자동사냥은 삭제되었다. 현재 사냥시작은 위의 타겟팅 없는 우클릭 유지 + 반복스킬 기능이다.

Qwen은 적·아군·모르는 객체를 분류한다. 모델은 입력 키를 임의로 만들지 않는다.
OpenCV는 미니맵/실제 이동/적 HP바/버프를 검사한다. 좌표·입력·스킬 간격·포커스·HP·중단 검증은 실행 코드가 맡는다.
객체를 기억하고 미확인 객체는 질문한다. 제자리사냥의 대상 갱신과 사냥시작의 타겟팅 없는 입력을 구분한다.

## 이동
예정 최종 목표는 유지한다. feedback_steps는 중앙 클릭 거리(%)를 반영하되 검증된 통로 길이로 제한한다. 지도 0.8초 이내이면 최소 0.08초 간격으로 같은 목표 클릭을 이어간다. 클릭으로 정체 타이머를 초기화하지 않는다. 최종 목표의 15%(4~12px) 인근에서 다음 목표를 선택한다.
자동사냥·이동은 주황색 안내선 또는 핀이 있으면 우선 따라간다. 둘 다 없으면 미니맵의 연결된 통로 중앙을 탐색하며 미방문 길을 우선한다. 핀은 방향 기준으로 기억하며 예정 목표는 핀 쪽의 연결된 통로 안에 선택한다. 핀 좌표가 벽·맵 밖이면 접근 가능한 통로를 목표로 삼는다. 남아 있는 주황·적갈색 안내선 끝을 우선하고 막히면 연결된 통로로 우회한다. 핀이 가려져도 누적 좌표를 유지한다. 미방문 길과 방향 지시를 반영한다. 정체 1.2초이면 재계획한다. 핀 이동 중 자동 Qwen 분석은 하지 않는다. 이동 명령은 공격 없이 이동만 한다. 벽·미확인 지형은 클릭하지 않는다.
미니맵 위치·투영 배율·회전·창 크기는 navigation.json을 따른다. HUD·미니맵·캐릭터·아군 클릭은 차단한다. 검증된 통로는 직선화하고 벽 앞에서 클릭을 제한한다. 클릭선은 전송 당시 위치 기준이다.

## 공격·스킬·버프
이동에서 자동으로 공격 모드로 전환하지 않는다. 공격 스킬은 enabled와 disabled_actions, 등록 키와 성공 전송 이후 사용 간격을 따른다. 사냥시작은 기본 우클릭을 계속 유지하며 반복스킬을 병행한다.
빨간 잔량이 작아져도 같은 적을 연타한다. 빨강·검정 전체 바를 추적하고, 감소 후 완전 검정(HP 0)을 연속 3회 확인하면 종료한다. 바·추적 소실은 공격 중지 후 재확인하며 사망·아군으로 저장하지 않는다. 사거리는 input.json이 우선한다.
버프는 Qwen의 추측이나 쿨다운 인터벌로 발동하지 않는다. 미등록·검사 불가는 발동하지 않는다. 입력 실패는 성공으로 기록하지 않는다. 등록 아이콘 하나라도 보이면 모든 소실 상태와 재사용 대기를 해제한다.

## 중단·보정
기본 자동사냥은 꺼져 있다. 게임 비활성 시 입력을 중단하며 사용자가 버튼·핫키로 시작한다. 사냥 중단은 입력·Qwen을 해제하고 수동 조작을 유지한다. 일반 시작/재개는 이동 기능을 실행한다.
hud_mode=true/false에서 핫키·이동·공격·스킬 실행 정책은 동일하다. hud_mode는 HUD 정보 읽기만 제어하며 미검출 HP 때문에 공통 핫키를 차단하지 않는다. 자동 HUD 긴급 반응·보정·전투 재확인 작업은 이 실행 경로에서 비활성이다.
디아블로4 실행 설정은 runtime.json, 장치·연결 설정은 루트 config.ini에 둔다. 게임별 Agent가 달라지는 프로파일 전환은 프로그램 재시작으로 적용한다.
MOUSE ESP32, CONTROL, HOTKEY, HUNT ATTACK 상세 로그는 DEBUG에서만 표시한다.
HUD는 독립 읽기 경로를 사용한다. 저장한 HUD 보정 자료는 보존하며 자동 보정 작업을 핫키 실행의 선행 조건으로 삼지 않는다.

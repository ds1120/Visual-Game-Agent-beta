# 몹 판정과 웹 설정 적용 수정

## 적용

Agent를 Ctrl+C로 종료하고 변경 파일 ZIP을 기존 프로젝트 폴더에 덮어씁니다.

```powershell
py -m app.main --web --no-chat
```

웹 대시보드를 새로고침하고 새 토큰으로 연결합니다. 설정을 조절한 후 `현재 튜닝을 Agent에 적용`을 누르세요. 슬라이더 이동과 실험 기록 저장은 비교용이며, Agent 적용 버튼을 눌러야 게임 PC 설정이 바뀝니다. 적용은 일시정지 상태로 끝납니다. `시작 / 재개`를 누르면 실행합니다.

설정은 `app/profiles/<게임>/vision.json`에 저장됩니다. YOLO와 게임 창 제목은 해당 파일이 기준입니다. config.ini는 게임 선택, 캡처 방식, Qwen API, 입력 백엔드 등 시작 설정을 담당합니다.

## 확인한 원인과 수정

- YOLO의 monster 클래스가 외형 메모리에 없으면 최종 unknown으로 바뀌었습니다. 게임별 class_rules로 알려진 클래스는 직접 의미를 부여합니다. 미등록 클래스와 낮은 신뢰도는 Qwen으로 분류합니다.
- 기본 Diablo4 best 모델에만 monster/hostile(최소 0.6), item/neutral(0.7), obstacle/neutral(0.6) 매핑을 최초 1회 추가합니다. 기존 class_rules가 있으면 변경하지 않습니다. 다른 게임에는 자동 매핑하지 않습니다. 사람이 locked=true로 확정한 외형 분류는 매핑보다 우선합니다.
- 포함된 best.onnx는 512×512 고정 입력입니다. 다른 이미지 크기를 요청하면 같은 이름의 best.pt를 실제 추론에 사용합니다. 두 파일은 같은 학습 모델이어야 합니다. 커스텀 모델을 교체할 때 ONNX와 PT를 함께 교체하세요. PT가 없으면 크기 변경을 거절합니다. 실제 파일명은 웹에 표시합니다.
- 모델/장치/활성화/크기 변경은 사전 로드와 시험 추론을 통과한 뒤 저장·적용합니다. 실패하면 이전 파일과 실행 설정을 유지합니다. 웹 적용과 대화 수정에 적용됩니다.
- FPS, ROI, 탐지 주기, 신뢰도, 최대 탐지 수, 장치, 모델, 창 제목과 Qwen 객체 주기를 반영합니다. 0.05초 설정이 0.1초로 잘리는 문제를 수정했습니다.
- Qwen 객체 게이팅 ON: 미확정 객체만 검토. OFF: 확정 객체도 주기적으로 검토하며, 잠금·확정 메모리를 자동 덮어쓰지 않습니다. 통과율 %는 GPU 예측용 가정이며 강제 실행 확률이 아닙니다.
- 겹친 다른 클래스(몹과 아이템)가 클래스 무관 중복 제거로 사라지지 않게 했습니다. 설정 변경 전 시작한 캡처/HUD/YOLO 결과는 새 설정의 결과로 채택하지 않습니다.

## 웹에서 판정 단계 확인

실제 Agent 연결 영역의 YOLO 진단은 `탐지 → 신뢰도 통과 → 최종 객체 · 적 몹`과 실제 모델/크기/장치를 보여줍니다.

- 탐지 0: 캡처 대상·ROI·모델 학습 범위를 확인합니다.
- 탐지는 있으나 신뢰도 통과 0: 화면 크기·대상 크기·모델 정확도와 탐지 신뢰도를 확인합니다.
- 최종 객체는 있으나 적 몹 0: class_rules, locked 외형 분류, 클래스 이름, 판정 신뢰도를 확인합니다. 탐지 confidence와 class_rules.min_confidence는 별도 기준입니다.
- 적 몹이 있으나 공격하지 않음: 일시정지, HUD 준비, 게임 전경, 입력 backend=mock, 행동 정책을 확인합니다.

탐지 모델의 정확도 개선은 실제 게임 이미지로 별도 검증해야 합니다. 이 수정이 학습되지 않은 몹을 새로 학습시키지는 않습니다. 20~30ms 목표는 OpenCV+YOLO 처리 시간이고, Qwen 응답은 별도로 측정해야 합니다.

## 확인한 검사

기존 테스트와 신규 회귀 테스트: 64개 통과. 몹 클래스 직접 판정, 미등록/낮은 신뢰도 보류, 사용자 잠금 우선, Qwen 게이팅 전환, 고정 ONNX 크기 판독, PT 선택, 겹친 클래스 보존, 설정 마이그레이션, 모델 실패 시 미저장, 웹 설정 반영을 검사했습니다. 하드웨어 모델 실행은 테스트 경계에서 대체했으며 실제 Windows·GPU·게임 입력 성능은 측정하지 않았습니다.
